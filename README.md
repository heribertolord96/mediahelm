# MediaHelm — Product site

Public landing for **MediaHelm** (`com.mediahelm.app`): play-first LAN media for Android.

- **Live:** https://heribertolord96.github.io/mediahelm/
- **Privacy / Terms (canonical):** https://heribertolord96.github.io/mediahelm-legal/
- **App support:** heribertolord@gmail.com

Legal docs stay in the separate [`mediahelm-legal`](https://github.com/heribertolord96/mediahelm-legal) repo so Play Console and in-app links do not change.

## Stack

Vite · Tailwind CSS v4 · vanilla JS · GitHub Pages (`base: /mediahelm/`)

## Local

```bash
npm i
npm run dev
```

## Deploy

```bash
npm run deploy
```

Runs `vite build` then publishes `dist/` to the `gh-pages` branch. In the GitHub repo: **Settings → Pages → Branch: `gh-pages` / root**.
